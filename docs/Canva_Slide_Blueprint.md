## 🟢 Slide 1: หน้าปก (Title Slide)
*   **หัวข้อหลัก:** AI-Driven SIEM & Honeypot Dashboard
*   **หัวข้อรอง:** ระบบศูนย์ปฏิบัติการรักษาความปลอดภัยทางไซเบอร์อัจฉริยะ
*   **Visual:** พื้นหลังแนวลูกโลกโครงข่าย (Network Globe) หรือเส้นแสงวิ่งๆ

## 🔴 Slide 2: จุดเริ่มต้น (Why did we build this?)
*   **หัวข้อ:** ทำไมเราถึงสร้างระบบนี้ขึ้นมา?
*   **เนื้อหา:**
    *   **Pain Point:** เจ้าหน้าที่ความปลอดภัย (SOC) ต้องเผชิญกับหน้าจอ Log ที่มีแต่ตัวหนังสือมหาศาล (Alert Fatigue)
    *   **Problem:** การวิเคราะห์ข้อมูลการโจมตีต้องใช้เวลาและผู้เชี่ยวชาญเฉพาะทาง ทำให้ตอบสนองต่อภัยคุกคามล่าช้า
    *   **Goal:** ต้องการศูนย์บัญชาการ (Command Center) ที่สวยงาม ดูง่าย และมี AI เข้ามาช่วยทำงานแทนคน
*   **Visual:** รูปเจ้าหน้าที่กำลังเครียดกับหน้าจอ หรือกราฟสีแดงที่พุ่งสูงจนดูไม่ทัน

## ✨ Slide 3: จุดเด่นและความแตกต่าง (Why are we different?)
*   **หัวข้อ:** ความแตกต่างจากระบบทั่วไปที่มีอยู่ในตลาด
*   **เนื้อหา (เปรียบเทียบ):**
    *   **ระบบทั่วไป (Others):** อินเทอร์เฟซซับซ้อนใช้งานยาก, ต้องเขียน Rule เองทั้งหมด, ไม่มีระบบ AI ช่วยแปลผลแบบอัตโนมัติ, มีราคาแพง
    *   **ระบบของเรา (Ours):** 
        1. **AI-Powered:** ใช้ Generative AI ช่วยสรุปสถานการณ์เป็นภาษามนุษย์ทันที
        2. **Tailored UI:** ออกแบบหน้าจอแบบ Command Center เน้นความสวยงามและแสดงผล Real-time บนเบราว์เซอร์
        3. **Enterprise Ready:** ผูกระบบเข้ากับโครงสร้างองค์กรได้เลย (เช่น ใช้ KKU SSO ล็อกอิน)
*   **Visual:** ตารางเปรียบเทียบซ้าย-ขวา (Before/After หรือ Others/Ours) มีเครื่องหมายถูกสีเขียวฝั่งเรา

## 🔵 Slide 4: แหล่งที่มาของข้อมูล (Data Flow & Architecture)
*   **หัวข้อ:** ข้อมูลมาจากไหน และระบบทำงานอย่างไร?
*   **เนื้อหา:**
    *   **1. ดักจับ (Honeypot):** ระบบหลอกล่อ (เช่น Cowrie) เปิดพอร์ตทิ้งไว้เพื่อล่อให้แฮกเกอร์เข้ามาโจมตี
    *   **2. รวบรวม (Wazuh SIEM):** เอเจนต์ของ Wazuh คอยดึง Log การโจมตีส่งมาที่เซิร์ฟเวอร์ส่วนกลาง
    *   **3. ประมวลผล (NestJS Backend):** ฝั่ง Backend รับข้อมูลมาจัดฟอร์แมต เชื่อมต่อกับ LLM (AI) เพื่อแปลผล และบันทึกลง Database
    *   **4. นำไปใช้งาน (SvelteKit Frontend):** ผู้ใช้งานเปิด Web Browser ล็อกอินผ่าน SSO เพื่อดู Dashboard ได้จากทุกที่
*   **Visual:** แผนภาพ (Data Flow Diagram) ไล่จากซ้ายไปขวา (Honeypot -> Wazuh -> Backend -> Frontend)

## ✨ Slide 5: Core Feature 1 - SOC Command Center
*   **จุดใส่หน้าเว็บ:** *ใส่ภาพหรือวิดีโอหน้าจอ Dashboard หลัก*
*   **คำอธิบาย:** Global Threat Map (แสดงพิกัดแบบ Real-time), Top Attackers, Security Logs

## ✨ Slide 6: Core Feature 2 - AI Briefing
*   **จุดใส่หน้าเว็บ:** *ใส่วิดีโอหน้าต่าง AI Briefing ตอนที่ AI กำลังประมวลผลข้อความ*
*   **คำอธิบาย:** วิเคราะห์ Log เชิงลึก สรุปสถานการณ์แบบ Executive Summary และแนะนำวิธีป้องกันโดยอัตโนมัติ

## ✨ Slide 7: Core Feature 3 - Secure Access & Auditing
*   **จุดใส่หน้าเว็บ:** *ใส่ภาพหน้าต่าง Login ผ่านระบบ KKU SSO และหน้าประวัติ Audit*
*   **คำอธิบาย:** ยืนยันตัวตนระดับองค์กร (SSO) พร้อมระบบบันทึก Audit Logs อย่างโปร่งใส
